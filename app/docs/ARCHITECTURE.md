## Layout
```

  game/                 Pure rules engine (no React)

    gameEngine.ts       newGame, dealRound, reduce (the state machine)

  screens/              Home, Game, Tutorial, Rules, Settings
  components/           UI (see below)
  tutorial/             lessons.ts (10 lessons), evaluate.ts (checks learner picks with real scoring code)

```

## Phase state machine (`GameState.phase`)
`discard → cut → pegging → counting → (next round: discard…)`, or `gameOver` at any point a player reaches 121.

| Phase | Action | Effect |
|---|---|---|
| discard | `{discard, player, cardIds[2]}` | moves cards to crib; when crib has 4 → `cut` |
| cut | `{cut, index?}` | picks starter from `deck` (random if no index); jack starter = "his heels" 2 pts to dealer; → `pegging` |
| pegging | `{play, player, cardId}` | `applyPlay`: score via `scorePlay`, handle Go / last card / 31, `endSequence` resets count; when all cards played → `counting` |
| counting | `{confirmCount}` | awards current step (0 pone hand, 1 dealer hand, 2 crib); after step 2 deals next round with dealer swapped |

`GameState` also holds `hands`, `crib`, `starter`, `deck`, `scores` (`{front, back}` peg positions per player), `pegging` (pile, discarded, count, turn, lastPlayer, goBy, remaining), `counting` (step, target, owner, cards, result), `winner`, `lastEvents` (events from the latest transition), `eventSeq`.

`award()` applies items one at a time and stops the instant total hits 121 (sets `winner`, `phase='gameOver'`).

## useGame (src/hooks/useGame.ts)
Holds `stateRef` (source of truth) + `state` React mirror. `apply(action)` runs `reduce`. Effects:
- new round → deal animation lock (`DEAL_MS=1500`) + deal sounds
- `lastEvents` → staggered toasts (750ms apart), highlight cards, score sound/haptic
- `displayScores` lag behind real scores (420ms) so the peg animates after the card lands
- counting: cycles highlighted scoring combo every 1700ms
- `busy` lock after phase changes (input ignored)
- persistence: saves full state to AsyncStorage each change (`cribbage.game.v1`), removes on gameOver
- AI driver: schedules AI discard / cut (if AI is pone) / play with jittered "think" delay from `AI_DELAY[aiSpeed]`
- player actions: `tapCard` (discard toggle; pegging = tap to select, tap again to play), `dropCard` (drag up), `confirmDiscard`, `cutDeck`, `confirmCount`, `showHint`, `restart`
- `coach` string drives the message strip
Returns `{state, displayScores, busy, dealing, paused, setPaused, selected, toasts, highlight, shake, coach, activeItem, setActiveItem, actions}`.

## Screens
- **HomeScreen**: title, floating decorative cards, Continue (loads `cribbage.game.v1`, validated with `isStateRestorable`), New Game, Tutorial, Rules, Settings.
- **GameScreen**: `useGame` + `makeLayout`; renders `TableBackground`, `CribbageBoard`, `ScoreDisplay`s, `GameTable`, `CountingPanel`, `ToastLayer`, pause menu modal (with settings toggles), result overlay + `Confetti`. `gestureEnabled:false`.
- **TutorialScreen**: steps from `LESSONS`; interactive checks via `evaluateStep`; progress key `cribbage.tutorial.v1`; final step can launch a game (`playNow`).
- **RulesScreen / SettingsScreen**: static reference / settings form.

## Components
`AnimatedCard` (reanimated, drag/tap/shake, target positions), `PlayingCard`, `CardArt` (SVG faces/back, suit glyphs), `GameTable` (places all cards using layout), `CribbageBoard` (SVG board with two pegs), `ScoreDisplay` (+`AnimatedNumber`), `ScoreNotification`/`ToastLayer`, `CountingPanel`, `Effects` (`Confetti`, `CountBadge`, `DeckStack`), `Buttons` (`GoldButton`, `IconButton`, `ToggleRow`, `Segmented`, `Divider`), `ScreenFrame` (+`Panel`, `Heading`, `Body`), `TableBackground`.

## Settings (`cribbage.settings.v1`)
`sound, haptics, explanations, hints, difficulty ('easy'|'medium'|'hard', default medium), aiSpeed ('fast'450ms|'normal'900|'slow'1500)`.
